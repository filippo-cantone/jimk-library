# Mouse Chase

*Vivian Sathre*

Mouse creeps.

Cat purrs.

Cat sleeps.

Breeze rustles.

Cat stirs.

Mouse stops.

Cat s-t-r-e-t-c-h-e-s.

Whiskers twitch.

Mouse runs.

Cat chases.

Wind blows.

Leaf flutters.

Mouse grabs.

Wind swirls.

Leaf rises.

Mouse soars.

Cat leaps.

Cat misses.

Cat creeps.

Wind whispers. Mouse glides.

Leaf dips.

Cat springs.

Cat splashes.

Cat drips.

Leaf floats.

Mouse drifts.

Cat swats.

Leaf twirls.

Cat waits.

Tail switches.

Wind howls.

Water swells.

Mouse sails.

Cat wails.
